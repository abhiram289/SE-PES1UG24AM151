
# TC-04: Privacy / Soft-Deletion

This document contains the test case specification for **NFR-001: Privacy and Soft-Deletion** for the Alumni Mentorship & Mock Interview Platform.

## Objective

Verify that user profile data and feedback scorecards are protected from unauthorized access and that requested data can be soft-deleted within 24 hours.

## Test Case Details

| Field | Details |
|---|---|
| Test Case ID | TC-04 |
| Requirement ID | NFR-001 |
| Type | Non-Functional |
| Category | Privacy / Security |
| Priority | High |

## Coverage

- Protection of user profile data
- Protection of feedback scorecards
- Prevention of unauthorized access
- Processing of data deletion requests
- Soft-deletion within 24 hours

## Contents

The report includes the test objective, preconditions, test data, test procedure, expected results, and pass/fail criteria.
